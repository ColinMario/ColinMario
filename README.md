# 💫 About Me:
I like building simple, reliable things that get out of your way. Lately I’m exploring AI—turning small experiments into handy everyday helpers. I also tinker in a little home lab, setting up virtual machines with Proxmox just for the fun of it. Coffee keeps the ideas flowing; a judgmental cat approves (mostly). Uptime promise: never gonna give you up, never gonna let you down—unless the cat sits on the keyboard and ships early.
